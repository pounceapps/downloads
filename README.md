# PounceApps — Downloads

**Small, fast, native macOS apps with a retro heart and AI built in.**
Every PounceApp ships here as a signed, notarized `.dmg`.

[**Website**](https://pounceapps.com) · [**Homebrew tap**](https://github.com/pounceapps/homebrew-tap) · [**Discussions**](https://github.com/orgs/pounceapps/discussions)

## Install with Homebrew  *(recommended)*

```sh
brew tap pounceapps/tap
brew install --cask pouncesql   # AI-native SQL client
brew install --cask pouncepad   # AI-drivable text editor
brew install --cask retrocode   # 8-bit Assembly & BASIC IDE
brew install --cask morselhub   # AI message hub
```

Install one, or the whole family. `brew upgrade` keeps them current.

## Or download a DMG

Grab the latest from [**Releases**](https://github.com/pounceapps/downloads/releases) → open it → drag the app to **Applications**. Every build is signed with a Developer ID and **notarized by Apple**, so it launches with no Gatekeeper warnings.

## The apps

| | App | What it does |
|---|-----|------|
| 🧶 | **[PounceSQL](https://pounceapps.com/pouncesql.html)** | Native SQL client for **Azure SQL, SQL Server, PostgreSQL & SQLite** — with an AI assistant that writes queries, charts results, and diagrams your schema. Built-in MCP server. |
| 🐾 | **[PouncePad](https://pounceapps.com/pouncepad.html)** | An **AI-drivable text editor** — ~30-language syntax highlighting, Markdown + Mermaid preview, and a **Claude Code channel** built in. |
| 🔩 | **[RetroCode](https://pounceapps.com/retrocode.html)** | Code like it's **1980** — a real 8-bit CPU emulator, TRS-80-style **BASIC** with a graphics display, a modern editor, and an AI tutor. |
| 🐱 | **[MorselHub](https://pounceapps.com/morselhub.html)** | Your **AI message hub** — connects iMessage, RetroCode & webhooks to Claude and routes the replies back. Runs locally. |

## Requirements

macOS 12+ (Apple Silicon). PounceSQL requires macOS 13+.
