# PounceApps — downloads

Notarized macOS DMGs for **PounceSQL** and **PouncePad**.

Install with Homebrew:

```sh
brew tap pounceapps/tap
brew install --cask pouncesql
brew install --cask pouncepad
```

Or grab a DMG from the [Releases](https://github.com/pounceapps/downloads/releases). More at [pounceapps.com](https://pounceapps.com).
